# V’Lana — Activewear

Site de uma loja virtual de moda fitness feminina, com catálogo de produtos, filtros, montador de looks, sacola e checkout. Possui layout responsivo e estrutura para gestão de pedidos, estoque e pagamentos.

O projeto está em modo de demonstração, com produtos e preços ilustrativos.

## Stack utilizada

- **HTML5, CSS3 e JavaScript puro:** interface e interações, sem frameworks.
- **Node.js 24+:** scripts de build, prévia local e testes nativos, sem dependências npm externas.
- **Worker com Fetch API:** backend de pedidos, estoque e pagamentos.
- **D1 / SQLite:** banco de dados.
- **Mercado Pago Checkout Pro:** integração de pagamentos preparada para configuração e validação.
- **GitHub Actions:** automação de build e testes.
